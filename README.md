# Employee CRUD — Java 8 / Spring Boot 2.7.18

Prerequisites: JDK 8 and Maven 3.9.x. Confirm `java -version` and `mvn -version` both use Java 8.

Build: `mvn clean package`

Quick run with H2: `mvn spring-boot:run -Dspring-boot.run.profiles=h2`

MySQL: execute database.sql as a database administrator, then run `mvn spring-boot:run`.
The included credentials are local learning defaults. Override DB_USERNAME and DB_PASSWORD for your environment.
The JDBC SSL/public-key options are for local development.

Base URL: http://localhost:8080/api/employees

POST /api/employees — create (201)
GET /api/employees — list (200)
GET /api/employees/{id} — get (200 or 404)
PUT /api/employees/{id} — replace editable fields (200 or 404)
DELETE /api/employees/{id} — delete (200 or 404)

Sample POST/PUT JSON:
```json
{"name":"Chalindu Silva","email":"chalindu@example.com","department":"Engineering","salary":85000.00}
```

Name and email are required; salary must be non-null and greater than zero, with at most 10 integer digits and 2 decimal places. Department is optional. Email uniqueness is not enforced. ID is generated by the server and ignored on input. PUT requires all mandatory fields; omitting department clears it.

H2 console: http://localhost:8080/h2-console
JDBC URL: jdbc:h2:mem:employee_db
Username: sa
Password: empty
H2 data disappears when the process stops.

For IntelliJ: open pom.xml as a project, select JDK 8 for project SDK and Maven runner, import Maven, then run EmployeeApplication. For H2 add --spring.profiles.active=h2 as a program argument.
For Eclipse: File > Import > Maven > Existing Maven Projects; select this folder, configure JavaSE-1.8 using a JDK 8 installation, Maven > Update Project, then run EmployeeApplication as a Java Application. For H2 use the same program argument.

Troubleshooting:
- Port 8080 occupied: stop the conflicting application or set server.port=8081 and use that port in requests.
- Database connection refused: start MySQL and check host and port.
- Access denied: verify the MySQL account and DB_USERNAME / DB_PASSWORD.
- Unknown database: run database.sql.
- Java mismatch: correct JAVA_HOME, IDE project SDK and Maven runner; rebuild after changing.
- javax imports missing: use this exact Boot 2.7.18 POM and refresh Maven.
